# SoleMuse

SoleMuse 是面向鞋履及相关品类设计师的 AI 创意作品展示与交流平台。

当前阶段仅开发原生 JavaScript 微信小程序前端，工程骨架已经初始化。Node.js API 与 Web 端将在后续阶段接入，并共用同一套业务接口。
