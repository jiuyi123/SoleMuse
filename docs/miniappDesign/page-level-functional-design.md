# SoleMuse 微信小程序页面级功能界面设计 V1.0

## 1. 文档目的

本文将 `docs/miniappDesign/DesignPic` 下 9 张原型图转换为可供产品、设计、前端、后端和测试共同评审的页面级功能说明。产品范围以《AI 创意多模态全球时尚鞋履提示词平台 PRD V1.0》为准；原型中超出 PRD 或页面间不一致的内容会保留记录，但不会自动纳入一期开发。

本次原型不含独立登录页、通知详情页和榜单规则弹层。相关页面仍按 PRD 保留入口，详细视觉稿待补。

## 3. 全局界面与交互规范

### 3.1 视觉边界

原型中的手机外框、屏幕外山水背景、金属花饰、左右竖排文字和底部英文页脚属于展示包装，不属于小程序页面。实际开发只还原手机屏幕内的内容。

界面视觉语言为“东方山水 + 轻科技”：浅蓝灰水墨背景、深海军蓝正文、青蓝渐变主按钮、白色或半透明卡片、大圆角和轻阴影。文字信息必须保持足够对比度；水墨背景不得影响表单、数据和按钮可读性。

### 3.2 导航

- 顶部使用小程序安全区适配的导航栏，标题居中；返回按钮只出现在非 Tab 页面。
- 微信右上角胶囊为系统区域，页面元素不得侵入胶囊和状态栏。
- 底部固定五栏：首页、榜单、创作、消息、我的。
- 原型明确将“创作”设计为居中抬升的圆形加号。视觉还原阶段建议启用 `custom-tab-bar`；必须处理选中态、未读态、底部安全区及 Tab 页面切换。
- 登录拦截应保存目标路由。登录成功后回到原页面，或继续触发原操作。

### 3.3 通用组件

| 组件 | 主要内容 | 使用页面 |
| --- | --- | --- |
| 顶部导航栏 | 标题、返回、系统安全区 | 全部页面 |
| 自定义 TabBar | 五个入口、创作加号、选中态 | 五个一级页面 |
| 作品瀑布流卡片 | 封面、标题、作者、AI 来源、互动数字 | 首页、搜索、我的内容 |
| 排名卡片 | 名次、封面、标题、副标题、作者、热度 | 榜单 |
| AI 来源标签 | 工具/模型名称、非 AI、来源未标注 | 列表与详情 |
| 筛选胶囊 | 分类、风格、AI 来源、发布时间 | 搜索结果 |
| 页面状态 | 加载、空、失败、无权限、内容下架 | 所有数据页面 |
| 确认弹层 | 放弃编辑、下架、删除评论等 | 编辑与详情 |

### 3.4 列表与状态约定

- 列表首次进入显示骨架屏；下拉刷新更新首屏；滚动到底按游标加载下一页。
- 加载更多期间保留已有内容；失败时在列表底部提供重试，不整页清空。
- 空状态必须说明原因并提供可执行入口，例如清除筛选、去创作或重新加载。
- 图片使用懒加载和占位色；加载失败显示统一占位图，不改变卡片尺寸。
- 所有计数显示服务端确认值。`1.2k` 等缩写只用于展示，不回写数据。

## 4. 页面详细设计

### 4.1 首页

**目标与权限**

游客和登录用户均可进入，用于发现公开作品、搜索内容和进入创作流程。

**界面结构**

1. 顶部品牌 Hero：标题“AI 创意多模态全球时尚鞋履提示词平台”、品牌副文案和主题鞋履视觉。
2. 搜索入口：占位文案“搜索鞋款、风格、Prompt…”。点击进入搜索结果页并自动聚焦输入框。
3. 热门标签：原型展示“未来科技、颐绣灵感、运动潮流、可持续、AI 设计”。点击后进入带标签条件的搜索页。
4. 内容切换：原型展示“推荐、最新、关注”和宫格切换按钮。
5. 双列作品流：封面、标题、点赞数、作者头像/昵称、AI 工具标签。
6. 底部五栏导航。

**一期行为决策**

- 默认内容源采用“最新”，符合 R-16。
- “推荐”如保留，只能表示公开编辑精选或明确规则结果，不得使用个人画像算法。
- “关注”依赖关注关系，而 PRD 未定义关注功能；一期隐藏或置为不可用，待产品确认后再开发。
- 宫格切换可在一期只保留双列模式；如果支持切换，应只改变布局，不改变排序和数据源。
- 点击卡片进入作品详情；点击作者信息是否进入他人主页，PRD 未定义，暂不提供跳转。
- “开始创作”对游客触发登录，成功后进入发布作品页。

**页面状态**

加载时展示 Hero 和标签骨架；作品为空时提示“暂无公开作品，成为第一个发布者”；接口失败时保留搜索与创作入口，并提供重试。

### 4.2 搜索结果页

**目标与入口**

由首页搜索框、热门标签或筛选入口进入。游客可以使用全部公开搜索能力。

**界面结构**

1. 返回按钮和标题“搜索结果”。
2. 搜索框：显示当前关键词、清除按钮和搜索按钮。
3. 四个筛选器：分类、风格标签、AI 生成源、发布时间。
4. 排序切换：最新发布、热度排序。
5. 结果总数，例如“共 58 个结果”。
6. 双列作品卡片和列表结束提示。

**交互与规则**

- 搜索范围为标题、描述、标签和作者昵称，符合 R-18；Prompt 是否参与全文搜索需后端确认。
- 点击筛选器弹出单选或多选面板。分类和 AI 来源默认为单选，风格标签可多选，发布时间为预设区间。
- 搜索、筛选与排序变化后回到列表顶部，并重新请求第一页。
- 返回页面时保留关键词、筛选、排序和滚动位置。
- 点击清除按钮仅清空关键词；“清除全部筛选”同时恢复默认排序和条件。
- 搜索按钮提交时去除首尾空白；空关键词允许作为作品广场使用。

**状态**

| 条件 | 系统行为 | 用户反馈 |
| --- | --- | --- |
| 正在查询 | 禁止重复提交 | 结果区显示骨架屏 |
| 无结果 | 保留当前条件 | 显示清除筛选和返回广场入口 |
| 加载下一页失败 | 保留已有卡片 | 列表底部显示重试 |
| 网络恢复后重试 | 重新执行最后一次条件 | 成功后替换或追加结果 |

### 4.3 作品详情页

**目标与权限**

展示公开作品完整信息。游客可以查看；点赞、收藏、评论和回复要求登录。已下架作品禁止新增互动。

**界面结构**

1. 图片轮播：封面和详情图按上传顺序展示，原型使用“1/5”和圆点指示。
2. 顶部操作：返回、分享和更多。分享可使用微信分享能力；更多菜单仅展示当前用户有权限的操作。
3. 作品与作者区：标题、作者头像/昵称、发布时间、点赞、收藏和评论计数。
4. 生成来源区：使用工具、模型版本、作品类型。
5. Prompt 卡片：完整文本与复制按钮。
6. 创作说明和标签。
7. 评论区：评论总数、排序、评论、单层回复和评论点赞展示。
8. 底部评论输入栏与发布按钮。

**内容示例**

原型以“云境行者”为详情示例，工具为 Midjourney v6.1，标签包含运动鞋、东方美学、颐绣元素、山水意境、梦幻风格、产品设计。完整 Prompt 和创作说明已整理至 `mocks/fixtures/prototype-content.json`。

**交互与规则**

- 图片轮播支持左右滑动和点击预览；预览使用原始顺序。
- 点赞、收藏采用即时状态反馈，失败时回滚并提示；重复点击不得产生重复记录。
- Prompt 复制成功后提示“已复制”；空 Prompt 不显示复制操作。
- 评论仅支持文字，发布期间禁用重复提交；原型中的图片附件和 `@` 不属于 PRD，一期隐藏。
- 回复仅一层，展示被回复用户；删除仅对本人评论开放并二次确认。
- 评论排序原型显示“按热度”，但 PRD 未规定排序方式。建议提供“最新/热度”，默认最新，需后端确认。
- 原型中的作者等级 `Lv.4` 和“资深创作者”属于未定义成长体系，一期隐藏。

**异常状态**

- 作品不存在：显示不存在并返回上一页/首页。
- 作品已下架：作者本人可查看管理信息；其他用户显示下架状态，互动按钮禁用。
- 登录过期：保留待执行动作，重新登录后由用户确认继续。

### 4.4 榜单页

**目标与权限**

公开展示统一热度规则产生的作品排行，不因用户而变化，游客可访问。

**界面结构**

1. 周期切换：24 小时热榜、周榜、月榜。
2. 排行规则入口。
3. 前三名领奖台：第 1 名居中突出，第 2、3 名位于两侧。
4. 第 4 名起的纵向列表：名次、缩略图、标题、副标题、作者和热度值。

**交互与规则**

- 切换周期重新请求榜单，保留当前周期选择。
- 点击作品进入详情；点击排行规则打开说明弹层。
- 规则弹层至少说明统计周期、参与范围、更新时间和热度构成，不公开可被滥用的反作弊细节。
- PRD 只要求公开热度榜，未明确 24 小时/周/月三个周期。若后端一期只提供一种榜单，则隐藏周期切换。
- 原型用爱心图标表达热度，容易被理解为点赞数；若热度包含多指标，应改用“热度”文案或火焰图标。

**原型示例数据**

前三名为云境行者 2.8k、未来之翼 2.4k、流光花穿 1.9k；第 4～8 名为机械花园、颐绣新生、赛博逐潮、自然共生、无界·NEXT。该组数据只用于开发占位。

### 4.5 发布作品页

**目标与权限**

所有完成注册的用户均可进入。游客先登录；没有设计师认证或人工审核门槛。

**界面结构与字段**

| 字段 | PRD 规则 | 原型建议值 | 一期处理 |
| --- | --- | --- | --- |
| 展示图片 | 必填；封面 + 多张详情图 | JPG/PNG，最多 9 张 | 数量/大小/分辨率待确认；保留顺序 |
| 作品标题 | 必填 | 最多 30 字 | 可作为建议默认，需产品确认 |
| Prompt | 必填 | 最多 500 字 | 可作为建议默认，需产品确认 |
| AI 工具/模型 | 必填 | 从预置列表选择 | 同时支持“非 AI 生成/来源未标注”规范值 |
| 模型版本 | 可选 | 原型合并显示 | 数据层独立字段 |
| 作品分类 | 必填 | 运动鞋、休闲鞋、潮流鞋、商务鞋、户外鞋 | 由后台字典或接口返回 |
| 风格标签 | PRD 可选 | 原型标为必填 | 以 PRD 为准：可选，可自定义数量待确认 |
| 创作说明 | 可选 | 最多 300 字 | 上限待确认 |
| 工作流/二次编辑说明 | 可选 | 原型未展示 | 可放入“更多信息”折叠区 |

**图片操作**

- 支持相册/相机选择、预览、删除、排序和设置封面。
- 第一张默认为封面；设置新封面后调整展示顺序。
- 上传中显示单图进度；失败的图片可单独重试。
- 未满足格式、大小、数量或分辨率规则时阻止加入，并说明具体原因。

**保存与发布**

- 保存草稿只要求存在至少一个可恢复的编辑内容，不执行全部发布必填校验。
- 发布时逐字段校验，自动滚动到第一个错误项，并在字段旁显示原因。
- 提交期间禁用保存和发布，防止重复作品。
- 保存草稿成功后留在当前页并显示保存时间；发布成功后进入作品详情。
- 有未保存改动时离开页面，弹出“保存草稿/放弃/继续编辑”。

### 4.6 编辑作品页

**目标与入口**

仅作品所有者可进入，通常从“我的作品”卡片更多菜单进入。页面复用发布页字段组件和校验规则。

**界面结构**

- 顶部展示作品状态、发布时间和“查看作品”入口。
- 图片区域支持更换封面、添加、删除和重排，最多数量与发布页一致。
- 表单字段必须与发布页一致，不维护两套分类或限制规则。
- 底部操作根据作品状态显示：下架作品、保存修改、发布/重新发布。

**状态与操作**

| 当前状态 | 可用操作 | 成功后状态 |
| --- | --- | --- |
| 草稿 | 保存、发布 | 草稿或已发布 |
| 已发布 | 保存修改、下架 | 保持已发布或变为已下架 |
| 已下架 | 保存修改、重新发布 | 已下架或已发布 |

一期没有人工审核流程，因此“已发布作品保存修改”默认直接更新公开内容；生成来源的修改记录需由服务端保留，符合 R-15。下架操作必须二次确认，下架后禁止新增点赞、收藏和评论。

**原型不一致处理**

- 发布页分类为鞋类，编辑页分类为“运动潮流/国风新中式/概念设计”等风格概念。正式实现必须使用同一分类字典，风格概念归入标签。
- 发布页创作说明上限为 300，编辑页显示 200。统一使用待确认的单一限制。
- 编辑页在标题下出现未标注短句“一双行走在山水之间的鞋，步履生花。”，PRD 没有独立副标题字段；一期并入创作说明或删除。
- 已发布状态下“保存修改”和“重新发布”同时出现语义重复；“重新发布”只在已下架状态显示。

### 4.7 消息页

**目标与权限**

仅登录用户可查看。游客进入时显示登录引导，登录后返回消息页。

**界面结构**

1. 分类入口：全部、赞与收藏、评论、系统通知。
2. 消息列表：类型图标、标题、摘要、时间和关联作品缩略图。
3. 底部导航消息选中态；存在未读消息时可显示角标。

**消息类型与跳转**

| 类型 | 示例 | 点击去向 |
| --- | --- | --- |
| 点赞 | “有人点赞了你的作品” | 作品详情 |
| 收藏 | “新的收藏” | 作品详情 |
| 评论/回复 | 评论者和摘要 | 作品详情的目标评论位置 |
| 作品状态 | 发布、下架或资料变化提醒 | 作品详情或编辑页 |
| 系统通知 | 平台活动与必要提醒 | 通知详情 |

原型中的“你的作品已完成生成”暗示平台执行在线 AI 生成，与一期“不提供在线 AI 生成”冲突。开发数据应改为“作品发布成功”“作品已下架”等已有状态通知。

首次进入显示骨架；空状态显示“暂时没有新消息”；关联作品已下架时仍可查看消息文本，但跳转后展示下架状态。已读规则、批量已读和角标聚合方式待产品与后端确认。

### 4.8 个人资料页

**目标与权限**

展示和维护本人资料，提供个人内容入口。原型页面标题为“我的”，与底部 Tab 一致。

**一期界面结构**

1. 头像、昵称、地区、职业/角色、个人简介和擅长品类。
2. 编辑资料按钮，进入资料编辑页。
3. 统计区：作品数可展示；其他统计仅展示 PRD 已定义的数据。
4. 资料字段列表，便于逐项编辑。
5. 我的作品、收藏、点赞和评论入口。
6. 品牌横幅可作为非关键运营位；无配置时不占位。

**字段规则**

昵称、头像、地区、职业/角色和擅长品类来自 R-02；必填项、长度、选项字典与隐私告知仍待确认。原型增加“个人简介”，可作为可选字段，但需产品确认后进入正式数据契约。

**超出一期内容**

原型展示获赞、关注、粉丝、用户签名、等级和“我的成就”。PRD 未定义关注关系、粉丝、成长等级或成就系统，一期不实现其数据和跳转。若需要视觉占位，应使用不可交互的产品介绍，不应伪造用户统计。

### 4.9 我的内容页

**目标与权限**

仅登录用户可进入，集中查看“我的作品、我的收藏、我的点赞、我的评论”。

**界面结构**

1. 简化个人信息：头像、昵称、简介和编辑资料入口。
2. 四项统计和四个内容 Tab，计数与列表接口一致。
3. 内容区域：原型以双列作品卡片展示标题、日期、浏览、点赞、评论、标签和更多菜单。

**按 Tab 的展示差异**

- 我的作品：展示草稿/已发布/已下架状态；更多菜单含编辑、发布/下架。只有此 Tab 显示作品管理操作。
- 我的收藏：展示收藏的公开作品；已下架内容显示不可用状态，并允许取消收藏。
- 我的点赞：展示点赞过的公开作品；支持进入详情，不在列表中直接取消以避免误操作，是否支持由交互稿确认。
- 我的评论：优先展示评论摘要、发布时间和关联作品，而不是强行复用纯作品卡片；点击定位到详情评论。

切换 Tab 时缓存各自列表与滚动位置。列表为空时分别提供去发现或去创作入口。删除、下架等操作成功后同步更新当前列表及顶部计数。

## 5. 权限与登录拦截

| 操作 | 游客 | 登录用户 | 作品作者 |
| --- | --- | --- | --- |
| 浏览首页、搜索、榜单、公开详情 | 允许 | 允许 | 允许 |
| 点赞、收藏、评论、回复 | 引导登录 | 允许 | 允许 |
| 发布作品 | 引导登录 | 允许 | 允许 |
| 编辑、下架作品 | 禁止 | 仅本人作品 | 允许 |
| 查看消息和我的内容 | 引导登录 | 仅本人数据 | 仅本人数据 |
| 删除评论 | 禁止 | 仅本人评论 | 仅本人评论；一期不授予作品作者额外删除权 |

前端权限用于控制入口和反馈，服务端仍必须校验资源所有权，不得依赖前端隐藏按钮实现授权。

## 8. 页面级验收要点

1. 9 张原型涉及的页面都有明确路由、入口、返回路径、角色权限和状态反馈。
2. 首页、搜索、榜单和详情对游客可用；受保护操作能登录并返回原目标。
3. 列表支持首次加载、刷新、分页、空态和失败重试，切换筛选不会混入旧数据。
4. 发布与编辑使用同一字段定义，图片顺序和封面关系稳定，重复提交被阻止。
5. 点赞、收藏和评论失败时能回滚；已下架作品不能新增互动。
6. 我的内容四个 Tab 使用对应数据和空态，管理操作只对本人资源开放。
7. 原型中的超范围功能不会因为视觉存在而被默认实现。
8. 所有开发素材从 `asset-manifest.json` 引用；正式发布前完成素材权属确认或替换。

## 9. 待确认事项

- 正式登录方式及隐私授权文案。
- 图片格式、单图大小、数量、分辨率和上传方案；原型建议 JPG/PNG、最多 9 张。
- 标题、Prompt、创作说明和自定义标签的最终长度限制。
- 分类、风格标签、AI 工具/模型的正式字典及“非 AI/来源未标注”的选择方式。
- 排行热度公式、更新频率和周期范围。
- 评论排序、评论点赞是否属于一期。
- 消息已读、角标、聚合和清理规则。
- 是否批准个人简介、浏览量和品牌横幅进入一期。
- 原型图片与头像的正式使用授权及高清源文件。
